# Sheduler
## Це простий додаток для створення події у календарі.

Щоб створити подію, виберіть дату, після цього виберіть час, натисніть "Далі". Введіть своє ім'я, електронну пошту, додайте електронну пошту гостей, введіть коментар і натисніть кнопку "Scedule event". У діалоговому вікні збережіть файл .ics події

## Використані бібліотеки та технології:
- React - верстка
- Tailwind - стилі
- Redux, Redux-toolkit - управління станом
- react-day-picker - бібліотека календаря для вибору дати
- Yup - валідація даних форми
- react-timezone-select - бібліотека для парсингу та роботи з часовими поясами
- react-select - ui для вибору часового поясу
- react-hot-toast - бібліотека для виводу коротких сповіщень
- ical-generator - генерація .ics файлу
- vite - збірка проєкту
